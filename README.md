# Responsive 3D Team Carousel

A modern and responsive team carousel built with pure HTML, CSS and JavaScript.

The active team member is displayed in the center, while the other cards are positioned behind it to create a layered 3D-style effect.

## Features

- Responsive design
- 3D-style card layout
- Smooth animated transitions
- Previous / next navigation
- Pagination dots
- Keyboard arrow navigation
- Mobile swipe support
- Dynamic team member name and role
- No frameworks required

## Technologies

- HTML5
- CSS3
- JavaScript
